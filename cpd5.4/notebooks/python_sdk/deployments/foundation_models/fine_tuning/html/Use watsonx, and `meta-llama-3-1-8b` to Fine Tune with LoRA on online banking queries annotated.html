Use watsonx, and meta-llama/llama-3-1-8b to Fine Tune with LoRA on online banking queries annotated¶

Disclaimers¶

  • Use only Projects and Spaces that are available in watsonx context.
  • If the IBM Cloud Pak® for Data cluster is air-gapped, all external data used in this notebook must be provided manually.

Notebook content¶

This notebook contains the steps and code to demonstrate support of LoRA Fine Tuning in watsonx.

Some familiarity with Python is helpful. This notebook uses Python 3.12.

Learning goal¶

The goal of this notebook is to demonstrate how to:

  • upload of dataset with prompts
  • trigger fine tuning process
  • review of fine tuning process details
  • deploy fine-tuned model
  • inference of fine-tuned model
  • compare with base model

Contents¶

This notebook contains the following parts:

  1. Set up the environment
  2. Preparing data for Fine Tuning training process
  3. Initialize Fine Tuning experiment
  4. Run Fine Tuning
  5. LoRA Fine Tuning details
  6. Create the Base Foundation Model Asset
  7. Create the Deployment of Base Foundation Model using the Base Foundation Model Asset
  8. Create the LoRA/QLoRA deployment by providing the LoRA/QLoRA base model asset and Base Foundation Model Deployment ID
  9. Preparing data for testing process
  10. Foundation Models Inference on IBM watsonx.ai
  11. Comparison of prediction results
  12. Cleanup
  13. Summary and next steps

This example uses the Banking77 training dataset with 200 samples.

In [6]:
import json
from pathlib import Path

import pandas as pd
import wget

filename = "train.csv"
base_url = "https://raw.githubusercontent.com/PolyAI-LDN/task-specific-datasets/master/banking_data/"

path = Path.cwd() / filename
if path.exists():
    path.unlink()
wget.download(f"{base_url}{filename}")

banking_df = pd.read_csv("train.csv").sample(n=200, random_state=42)

data = [
    {"input": row["text"], "output": row["category"]}
    for _, row in banking_df.iterrows()
]

ft_training_data = "ft_training_data.json"
with open(ft_training_data, "w", encoding="utf-8") as json_file:
    json.dump(data, json_file, indent=4, ensure_ascii=False)
